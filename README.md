# Angel Mercado — Scoop Bucket

Bucket de Scoop con herramientas de desarrollo de software.

## Agregar el bucket

```sh
scoop bucket add angel https://github.com/Angel-Mercado10/scoop-bucket
```

## Herramientas disponibles

| App | Descripción |
|-----|-------------|
| `ard-agent-ai` | ARD-ARCHITECT — agente de IA para decisiones arquitectónicas |

## Instalar

```sh
scoop install angel/ard-agent-ai
```
